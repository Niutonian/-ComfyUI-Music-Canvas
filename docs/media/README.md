# One song. Two interpretations.

These two 15-second excerpts come from existing Music Canvas generations. Both use the same portion of **Herbert & Momoko — Need to Run**, **00:30–00:45**. Only the first 15 seconds of each longer generated video are shown; no shots were regenerated or rearranged for this comparison.

The concept choices are from those recorded generations; an index does not name a permanently fixed style. This is an illustration of creative variation, not a controlled test that isolates a single setting. Matching soundtracks do not establish exact beat synchronization or a seamless loop.

`comparison-a.mp4` and `comparison-b.mp4` contain the shared soundtrack. The GIFs are reduced-size, silent previews of the same clips. Video pixels were re-encoded for publication and the audio excerpt was encoded once and reused in both MP4s. Embedded ComfyUI workflow/prompt metadata and original run information were stripped. Source assets were preserved.
